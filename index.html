SnowKeep

A private household management app

SnowKeep is a personal, self-hosted application built for private household use — task tracking, medication reminders, financial visibility, and home infrastructure monitoring, all in one place. It is not a commercial product, not publicly distributed, and has no public user base.

Who uses it

SnowKeep is used exclusively by its developer and one caregiver. It is a closed, private application with no sign-ups, no public access, and no third-party users.

What it does

Household and personal task tracking, medication schedules and dose reminders, a private view of bank balances and transactions via Plaid, a built-in email client for the household's own mail accounts, and monitoring for self-hosted home infrastructure (Nextcloud, Home Assistant, Mailcow, Portainer) — all from one app.

How it's built

Built as a native mobile and desktop application using Tauri and SvelteKit, backed by a self-hosted PocketBase instance. All data stays on private infrastructure.

Bank connectivity

Plaid is used solely to read account balances and transaction history for personal budgeting. No payments, transfers, or financial actions are initiated through the app.

Data & privacy commitments

  • User data is collected and stored on this app's own private, self-hosted infrastructure — never sold, and never shared with any third party beyond what's explicitly disclosed on this page.
  • Medication, task, and financial data are stored only on private, self-hosted infrastructure.
  • Financial data retrieved via Plaid is stored only on private, self-hosted infrastructure — the app does not initiate payments, transfers, or any financial transactions, and bank credentials are never stored, since authentication is handled entirely through Plaid Link.
  • Home infrastructure credentials (Nextcloud, Home Assistant, Mailcow, Portainer) are entered by the user and used only to connect to their own self-hosted services.
  • This application is not available to the public and has no commercial intent.
